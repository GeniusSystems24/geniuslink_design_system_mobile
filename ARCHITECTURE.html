GeniusLink Mobile — Full App

A Flutter port of the complete GeniusLink mobile app: authentication, the four bottom tabs, and every sub-screen reachable from the More menu — 60+ screens in all. Dark-only (matching the web demo), bilingual EN/AR strings, structured with a strict Model · View · Controller split.

Controller — NavController (ChangeNotifier) View — screens + shared kit 60+ screens No 3rd-party packages

Architecture

lib/ main.dart MaterialApp (dark) → AppRoot controllers/ nav_controller.dart auth gate · active tab · sub-screen stack views/ app_root.dart navigator shell (auth → tabs → sub-stack) screen_registry.dart id → title/back (SUB_TITLES) + id → widget kit/ shared widgets — ports of window._mob / _mui / _minv / banking m_colors · m_icons · m_widgets · m_inputs · m_shell · m_inv_kit · m_bank_kit screens/ one file per feature area (14 files) auth · dashboard · accounts(+extra) · stores · more ledger · journal · banking_cash · banking_transfer inventory · inventory_extras · currencies · contacts · reports · users settings_org · settings_team · settings_platform

Screens ported (every entry routes)

Design-system components (path dep · v2.8.1)

The app consumes the sibling geniuslink_design_system package for its three data components; their theme extensions are registered on the dark theme in main.dart so all three blend with the MCard chrome.

Tree Account Tree screen — typed Tree<Account>, builders read row.node.value (search · expand/collapse · indent guides · roll-up balances) ReadableTable wrapped as MTable (m_widgets) — Trial Balance · Inventory Valuation · Audit Log; click-to-sort + TSV copy (keys from cell text) + opt-in quick-search AutoSuggestionsBox wrapped as MSuggest (m_inputs) — Create-Account Parent/Currency pickers · journal-line account combo · the More menu is a spotlight over every screen

Run it

# from the project root cd geniuslink_design_system_mobile flutter pub get flutter run # device / emulator / -d chrome

Sign in on the login screen (any credentials enter the app). One path dependency (geniuslink_design_system, synced to v2.8.1) supplies the Tree / ReadableTable / AutoSuggestionsBox components; everything else is flutter only. Fonts fall back to the platform UI font until the GL families are dropped into assets/fonts/.
