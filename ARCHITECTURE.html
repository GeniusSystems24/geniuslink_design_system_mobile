Design system layers

package:super_core/super_core.dart Single token file: the M class with surface, foreground, brand, and font constants. Dark-only (mobile is always dark). tint(color, alphaHex) and tintPct(color, pct) helpers used throughout.
components/ layout: MIcons.of(name) + Eyebrow, MCard (marker bar · title · sub · right slot), MField (read-only preview), Mini (stat tile), Avatar, KV, MScroll (gap-spaced ListView). feedback: PillTone enum + Pill. buttons: MBtnVariant + MBtn (Material InkWell, 48px). navigation: MAppBar (back · title · Arabic gloss · action slot) + MTabBar (4 tabs: Home · Accounts · Stores · More).
adapters/form/m_inputs TInput (controlled, icon slot, RTL), TPassword (show/hide suffix), TSelect (dropdown), TSwitch, TCheckbox, Segmented (horizontal pill row), SearchInput, MSuggest (AutoSuggestionsBox wrapper), mSuggestions() helper.
adapters/table/m_table MCol descriptor (flex / fixed / align / sortable / numeric) + MTable wrapping ReadableTable<List<Widget>>. Click-to-sort headers, TSV copy, opt-in quick-search bar (showSearch), whole-row tap (onRowTap). mCellText() walker powers sort keys and copy.
adapters/banking/m_bank_kit Reusable banking primitives: MMoney (large accented amount field), MMethod (4-up payment chip selector), JournalPreview (debit/credit rows), FromToFlow (vertical card flow), FxTiles (3-up FX grid), AuditGrid, BKV, BankNote. Not in kit.dart — imported only by banking screens.
adapters/inventory/m_inv_kit Reusable inventory/form primitives: ISection (collapsible card), IField (locked/select/icon variants), ITextarea, Scanner (barcode placeholder with corner brackets), QtyStepper, ProductRow, AddProductBtn/AddLineBtn, UploadBox, IToggle, InfoNote, ActionRow. Not in kit.dart — imported by inventory, journal, and ledger screens.

Workspace (NavCubit)

NavCubit Cubit<NavState> at workspace/presentation/bloc/. State (Equatable): auth gate (authed, authScreen), active bottom tab (tab), sub-screen stack (stack: List<String>). API: login() · logout() · showAuth() · selectTab() · go(id) · back(target?) · home().
WorkspacePage Replaces the old AppRoot. Auth gate: routes to LoginScreen/SignUpScreen/ForgotScreen. Tab shell: MAppBar + tab body + MTabBar. Sub-screen: MAppBar (with back) + buildSubScreen(). Full-bleed screens (e.g. mobileDashboard) bypass the standard app bar.
app/router/app_router.dart Houses subTitles map (screen id → title/ar/back), portedScreens set, fullBleedScreens set, buildSubScreen() switch dispatch, buildTabScreen(). Imports all 20 feature screen files.

State management

flutter_bloc Cubit-first multi-tenant · DB-per-tenant AppBlocObserver
control-plane (root)ThemeCubit · AuthBloc · TenantCubit · NavCubit live above MaterialApp — tenant-agnostic, survive a switch.
tenant-scopedThe authed tab/sub shell + every list/form/settings cubit + MobileDashboardCubit live inside TenantScope, under ValueKey('tenant:<id>').
TenantScopewatches TenantCubit.activeTenantId; a switch (or logout) re-keys the subtree → Flutter destroys the old tree, closing that tenant's TenantDatabase, and builds fresh. No tenant state survives.
isolation guardTenantDatabase.guard(tenantId) throws on cross-tenant access; each tenant routes to its own tenant_<id>.db.
sharedcore/bloc/: LoadStatus · generic ListCubit<T> · FormCubit (values/dirty/validate/submit).
